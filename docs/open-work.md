# Open work

Deferred until the owner requests work beyond initial setup, in playbook order.

1. Identify the supplied release and confirm target/approach with the owner.
   Acceptance: reproduce the pinned archive checksum, document the verified release,
   CPU/loader and service requirements, and record agreed target decisions.
2. Add reproducible extraction that preserves Macintosh forks and metadata.
   Acceptance: verified inputs, recorded tool versions and repeatable output hashes;
   original and extracted bytes remain ignored.
3. Establish the original Macintosh reference loop using the existing ports' harnesses.
   Acceptance: a bounded unattended run reaches a positively identified milestone
   and captures reproducible evidence using project-owned process/state directories.
4. Map the executable and external services, then select runtime components to reuse.
   Acceptance: reference-validated executable image, documented code/data and service
   inventory, and pinned provenance for reused components before port implementation.
